# Pure Black

OLED-friendly true black preset. Setting ID `pure-black`, picker label **Pure Black**.

- Canvas, focused pane, and composer are `#000000`.
- Inactive panes and chrome lift to `#0f0f0f` so focus stays visible.
- Prompt cards `#1a1a1a` without prompt-age tint. Code blocks `#0a0a0a`.
- Neutral gray ink and focus outline. Blue only for links and selection.

Render: `python3 scripts/screenshot.py --theme pure-black target/pure-black.png`.
